# Canvas 图形编辑器

这是一个基于 Canvas API 的图形编辑器，使用了面向对象设计模式实现。通过该编辑器，您可以创建、编辑和移动各种图形。

## 功能特性

- ✏️ 创建多种图形：圆形、矩形等
- 🖱️ 拖拽移动图形
- 🎨 编辑图形属性：颜色、边框、透明度等
- 📝 在图形上添加文字
- 🔄 调整图形大小
- 🖼️ 上传和管理图片
- 🔀 纯色/图片模式切换
- 💾 保存和加载设计

## 项目结构

```
src/
├── core/             # 核心实现类
│   ├── GraphView.ts  # 画布视图类
│   ├── GraphNode.ts  # 图形节点基类
│   ├── CircleNode.ts # 圆形节点类
│   ├── RectNode.ts   # 矩形节点类
│   ├── ImageNode.ts  # 图片节点类
│   ├── DataModel.ts  # 数据模型类
│   ├── Selector.ts   # 选择器类
│   ├── Editor.ts     # 编辑器类
│   └── index.ts      # 导出所有类
├── components/       # Vue组件
│   └── GraphEditor.vue # 图形编辑器组件
├── App.vue           # 应用入口组件
└── main.ts           # 应用入口
```

## 设计模式

该项目使用了以下设计模式：

1. **策略模式**：不同图形节点类实现了各自的绘制逻辑
2. **组合模式**：图形节点组成了图形树
3. **观察者模式**：事件监听系统
4. **工厂方法**：创建不同类型的图形节点

## 使用方法

1. 点击左侧面板中的"添加圆形"或"添加矩形"按钮，在画布上添加相应图形
2. 点击"使用自定义图片"上传并添加图片
3. 点击画布上的图形选中它，右侧面板将显示其属性
4. 在右侧面板中编辑图形的属性，如颜色、边框等
5. 对于图片节点，可以在"图片"和"纯色"模式之间切换
6. 拖动图形可以改变其位置
7. 点击并拖动图形右下角的控制点可以调整大小
8. 使用"保存"按钮保存当前设计，使用"加载"按钮恢复之前的设计

## 图片处理功能

- **上传图片**：点击左侧面板中的"使用自定义图片"按钮上传图片
- **替换图片**：选中图片节点后，点击右侧面板中的"替换"按钮
- **纯色/图片切换**：选中图片节点后，在右侧面板顶部的选项卡中切换
- **圆角设置**：可以调整图片的圆角大小，适用于创建圆形或圆角图片
- **添加文字**：可以在图片上添加文字说明
