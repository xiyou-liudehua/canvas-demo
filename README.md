# Canvas 编辑器组件

这是一个基于 Vue3+TypeScript+Canvas 的交互式编辑器组件，可用于创建自定义弹窗设计。

## 功能特点

- 支持背景层设置（纯色/图片）
- 支持添加按钮元素（最多 10 个节点）
- 支持上传和添加自定义图片
- 支持拖拽调整元素位置
- 支持按钮样式自定义（颜色/图标/文字）
- 支持图层优先级管理（后添加的优先级更高）
- 背景层优先级最高

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 如何使用

1. 点击左侧面板中的"按钮"按钮添加按钮元素
2. 点击"使用自定义图片"上传图片
3. 在右侧面板中编辑选中元素的属性
4. 拖拽元素调整位置
5. 点击"保存提交"按钮保存设计

## 技术栈

- Vue 3
- TypeScript
- Canvas API
